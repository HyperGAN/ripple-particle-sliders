# Explicit continuous width-5120 proposal

The current [source proposal](../src/ripple_particle_sliders/profiles/continuous5120.json)
binds the full native 5120-coordinate response and its continuous penalty
domain to the published ParticleGAN release. The
`ripple-continuous-profile-audit` command checks the installed sources and
can verify the exact release wheel with `--candidate-wheel`. This audit
reports source provenance. Use the [native backend](../backends/ripple-native/README.md)
for its independent runtime admission requirements.
